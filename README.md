# Clinic-Appointments-
Doctor Appointment Booking System - Advanced SWE

## Business
A clinic appointment booking system that allows patients to view doctors' available slots and request appointments.

## Twist Rule
Each patient can have at most 3 upcoming appointments.

How to use
1.Choose Patient or Doctor from the main menu.
2.Patient: view a doctor's available slots (R1), book a slot (R2), see "My appointments".
3.Doctor: view pending requests and accept or decline them (R3).
4.A patient can have at most N = 3 upcoming appointments (R4). Only future Pending + Accepted appointments count; Declined, Cancelled and past ones do not.
